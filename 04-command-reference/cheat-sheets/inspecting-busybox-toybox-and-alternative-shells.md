| Command | What you can do with it |
| --- | --- |
| `busybox` | Print BusyBox help and compiled-in applets. |
| `busybox --list` | List compiled-in BusyBox applet names. |
| `busybox --list-full` | List BusyBox applets with their installation paths. |
| `busybox COMMAND --help` | Read help for a BusyBox applet. |
| `toybox` | List available Toybox commands. |
| `toybox --help` | Read Toybox usage information. |
| `toybox COMMAND --help` | Read help for a Toybox command. |
| `bash --version` | Print the Bash version. |
| `bash -n SCRIPT.sh` | Check Bash script syntax without running it. |
| `dash -n SCRIPT.sh` | Check dash script syntax without running it. |
| `ksh -n SCRIPT.sh` | Check ksh script syntax without running it. |
| `zsh -n SCRIPT.zsh` | Check zsh script syntax without running it. |
| `zsh --version` | Print the zsh version. |
| `fish --version` | Print the fish version. |
| `fish --no-execute SCRIPT.fish` | Check fish script syntax without running it. |
| `getent shells` | Read available login shells through the system database. |
| `ls -l /bin/sh` | Inspect the /bin/sh link or file. |
| `readlink -f /bin/sh` | Resolve the implementation behind /bin/sh. |
