| Command | What you can do with it |
| --- | --- |
| `snap list` | List installed snaps. |
| `snap find KEYWORD` | Search the Snap Store. |
| `snap info PACKAGE` | Read snap metadata and channel information. |
| `snap changes` | Inspect recorded snap changes. |
| `snap services` | List snap-managed services. |
| `sudo snap install PACKAGE` | Install a snap. |
| `sudo snap refresh PACKAGE` | Refresh a snap to an available revision. |
| `sudo snap remove PACKAGE` | Remove a snap and its managed installation state. |
| `flatpak list` | List installed Flatpak applications and runtimes. |
| `flatpak remotes` | List Flatpak remotes. |
| `flatpak search KEYWORD` | Search Flatpak application metadata. |
| `flatpak info APP_ID` | Inspect an installed Flatpak application. |
| `flatpak install REMOTE APP_ID` | Install a Flatpak application from a remote. |
| `flatpak update` | Update installed Flatpak applications and runtimes. |
| `flatpak run APP_ID` | Run a Flatpak application. |
| `flatpak uninstall APP_ID` | Uninstall a Flatpak application. |
| `nix --version` | Print the installed Nix version. |
| `nix profile list` | List entries in the current Nix profile. |
| `nix search nixpkgs KEYWORD` | Search nixpkgs using the newer Nix CLI when enabled. |
| `nix shell nixpkgs#PACKAGE` | Open a shell providing a nixpkgs package when the newer CLI is enabled. |
| `nix run nixpkgs#PACKAGE` | Run a nixpkgs package through the newer Nix CLI. |
| `nix flake show` | Inspect outputs of the current flake when flake support is enabled. |
