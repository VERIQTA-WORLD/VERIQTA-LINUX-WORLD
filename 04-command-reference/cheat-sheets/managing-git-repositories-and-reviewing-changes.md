| Command | What you can do with it |
| --- | --- |
| `git --version` | Print the Git version. |
| `git status --short` | Show concise working-tree and staging state. |
| `git clone REPOSITORY_URL` | Clone a repository into a new directory. |
| `git remote -v` | List configured remote URLs. |
| `git fetch origin` | Download remote objects and references without merging. |
| `git branch --show-current` | Print the current branch name. |
| `git branch -a` | List local and remote-tracking branches. |
| `git switch BRANCH` | Switch to an existing branch. |
| `git log --oneline --graph --decorate -20` | Inspect recent history with branch relationships. |
| `git show COMMIT` | Inspect a commit and its changes. |
| `git diff` | Inspect unstaged changes. |
| `git diff --stat` | Summarize unstaged changes by file. |
| `git diff --check` | Check changed lines for whitespace errors. |
| `git diff --cached` | Inspect staged changes. |
| `git diff BASE...HEAD -- PATH` | Compare a path against the merge base of two revisions. |
| `git ls-files` | List tracked files. |
| `git grep PATTERN` | Search tracked content. |
| `git blame -- FILE` | Inspect line attribution for a file. |
| `git add -- FILE` | Stage a specific file. |
| `git commit -m 'MESSAGE'` | Create a commit from staged changes. |
| `git push origin BRANCH` | Push a branch to origin. |
| `git pull --ff-only` | Fetch and update only when a fast-forward is possible. |
| `git tag --list` | List tags. |
| `git stash list` | List saved stashes. |
| `git worktree list` | List attached worktrees. |
