**Status: planned.** This page defines scope; lessons and tested exercises have not been built yet. We will develop this collection folder by folder.

## Planned coverage

- Namespaces, cgroups and host boundaries

- Container storage and networking

## Standard for future material

Explain the concept and prerequisites, provide a reproducible isolated setup, practise the operation, inspect expected evidence, investigate an appropriate failure, verify recovery and document cleanup. Record actual validation environments and limits.
