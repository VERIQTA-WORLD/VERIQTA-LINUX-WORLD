# Start here

![Start here](../assets/images/00-start-here-cover.svg)

Choose a Linux goal, find an appropriate starting point and practise in an environment you can recover. You do not need to read every collection in order, and completing a walkthrough is different from independently understanding its result.

## Your first route

1. Read [how to use Linux World](how-to-use-linux-world.md) to understand lessons, references, labs and validation labels.
2. Choose a [learning path by goal and experience](choose-your-learning-path.md).
3. Prepare an [isolated learning environment](set-up-your-linux-environment.md) and read [lab safety](linux-lab-safety.md).
4. Start the relevant [existing lessons](../01-Beginner-to-Advanced), then connect them to [labs](../02-Labs) and [projects](../03-Projects).
5. Keep a [progress and evidence record](learning-progress-checklist.md).

## Pick your goal

| Goal | Starting material | What comes later |
| --- | --- | --- |
| Learn Linux for the first time | Existing lessons, file/text references and small isolated exercises | Gradually combine identity, processes, networking and storage |
| Use Linux on a desktop or workstation | Foundations and distribution selection | Folder 9 is planned; its desktop lessons are not built yet |
| Develop on Linux | Foundations, relevant existing labs/projects and command references | Dedicated workstation, automation and container tracks are planned |
| Administer Linux systems | Foundations, system administration and troubleshooting | Add tested automation, fleet operations and observability incrementally |
| Explore internals and modern operating models | Demonstrated foundations and independent projects | Dedicated internals and image/declarative tracks are planned |

See [the full path guide](choose-your-learning-path.md) for prerequisites, checkpoints and links. Planned collections are visible in the [root roadmap](../README.md); their presence is not a claim that course content is finished.
