# Start here

![Start here](../assets/images/00-start-here-cover.svg)

Choose a Linux goal, find an appropriate starting point and practise in an environment you can recover. You do not need to read every collection in order, and completing a walkthrough is different from independently understanding its result.

## Your first route

1. Read [how to use Linux World](how-to-use-linux-world.md) to understand lessons, references, labs and execution evidence.
2. Choose a [learning path by goal and experience](choose-your-learning-path.md).
3. Prepare an [isolated learning environment](set-up-your-linux-environment.md) and read [lab safety](linux-lab-safety.md).
4. Start the relevant [lessons](../01-Beginner-to-Advanced), then connect them to [labs](../02-Labs) and [projects](../03-Projects).
5. Keep a [progress and evidence record](learning-progress-checklist.md).

## Pick your goal

| Goal | Starting material | Continue with |
| --- | --- | --- |
| Learn Linux for the first time | Linux lessons, file/text references and small isolated exercises | Gradually combine identity, processes, networking and storage |
| Use Linux on a desktop or workstation | Foundations and distribution selection | [Desktop and workstation Linux](../09-desktop-and-workstation-linux/README.md) |
| Develop on Linux | Foundations, relevant labs/projects and command references | Workstation setup, reproducible automation and container isolation |
| Administer Linux systems | Foundations, system administration and troubleshooting | Automation, fleet operations and observability |
| Explore internals and modern operating models | Demonstrated foundations and independent projects | Linux internals, image-based hosts and declarative configuration |

See [the full path guide](choose-your-learning-path.md) for prerequisites, checkpoints and links. Browse all collections in the [Linux World directory](../README.md).
