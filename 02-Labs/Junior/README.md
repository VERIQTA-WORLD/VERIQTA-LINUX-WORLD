# Junior Linux labs

Build your Linux foundation through 70 numbered follow-along labs. Start with navigation, then work through files, access, processes, storage, networking, Bash and evidence-based troubleshooting.

[Linux World Labs](../README.md) · [Environment](../LAB-ENVIRONMENT.md) · [Safety](../LAB-SAFETY.md) · [Lab standard](../LAB-STANDARD.md) · [Progress](../PROGRESS-TRACKER.md)

## Before you begin

Use the environment and privileges stated in the selected lab. Start with JUN-001 if you are new to Linux; otherwise demonstrate the earlier checkpoints before skipping ahead. Read the full exercise and cleanup instructions before modifying your VM. The numbered guides below are the actual lab files; each opens directly.
