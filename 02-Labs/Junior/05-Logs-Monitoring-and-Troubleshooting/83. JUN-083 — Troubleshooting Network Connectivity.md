# Part 1 — Define the destination and affected operation

Record client, namespace, destination name/address, address family, protocol, port and expected application operation. A vague “ping fails” complaint does not define whether TCP or HTTP is affected. ICMP response, TCP connection and application correctness have different meanings.

For a real authorized destination, inspect your local routing and resolver context before changing it. On your Linux VM, these read-only commands inspect a local path:

```bash
getent ahosts localhost
ip route get 127.0.0.1
ss -lnt
ip -brief address show
```

`getent` follows the configured name-service path. A DNS-specific tool answers a different question and may not reflect hosts-file or other NSS behavior. A local loopback result does not validate a remote DNS server, gateway or firewall.

Your controlled exercise uses only the literal IPv4 loopback address. It deliberately excludes external routing, DNS and remote policy from the runtime test.

# Part 2 — Understand your safe local experiment

Your helper binds `127.0.0.1` on port 0, asking the OS to assign an available ephemeral port. It serves one fixed health response, exposes no directory listing and exits within ten seconds in the test. It supports a normal and wrong-content mode.

# Part 3 — Implement the bounded loopback helper

Create this helper before the local experiment:

<!-- lab:exercise-083-helper -->
```bash
cat > scripts/loopback-health.py <<'PY'
import argparse
from http.server import BaseHTTPRequestHandler, ThreadingHTTPServer
from pathlib import Path
import signal
import threading

parser = argparse.ArgumentParser()
parser.add_argument('--ready', type=Path, required=True)
parser.add_argument('--mode', choices=('good', 'wrong'), default='good')
parser.add_argument('--seconds', type=int, default=10)
args = parser.parse_args()
if not 1 <= args.seconds <= 20:
    parser.error('seconds must be 1..20')
stopping = threading.Event()
signal.signal(signal.SIGTERM, lambda *_: stopping.set())
signal.signal(signal.SIGINT, lambda *_: stopping.set())

class Handler(BaseHTTPRequestHandler):
    def do_GET(self):
        body = b'READY\n' if args.mode == 'good' else b'WRONG\n'
        status = 200 if self.path == '/health' else 404
        self.send_response(status)
        self.send_header('Content-Type', 'text/plain')
        self.send_header('Content-Length', str(len(body)))
        self.end_headers()
        self.wfile.write(body)
    def log_message(self, *_):
        pass

with ThreadingHTTPServer(('127.0.0.1', 0), Handler) as server:
    server.daemon_threads = True
    worker = threading.Thread(target=server.serve_forever,
                              kwargs={'poll_interval': 0.05}, daemon=True)
    worker.start()
    try:
        pending = args.ready.with_suffix('.pending')
        pending.write_text(str(server.server_port))
        pending.replace(args.ready)
        stopping.wait(args.seconds)
    finally:
        server.shutdown()
        worker.join(timeout=2)
        if args.ready.exists():
            args.ready.unlink()
        pending = args.ready.with_suffix('.pending')
        if pending.exists():
            pending.unlink()
PY
```

Explain the two independent outcomes: HTTP status and body content. The wrong mode intentionally returns 200 with the wrong body. The helper is a bounded teaching server, not hardened or suitable for public deployment.

Daemon request threads allow shutdown to complete even if a client leaves a request unfinished. The lifetime bound still needs independent supervision if you adapt the design to a real service.

# Part 4 — Run and verify all three local outcomes

The following test disables HTTP proxy use, waits for readiness, compares exact bytes and always stops its own child. It then attempts the old local endpoint immediately after shutdown to observe the expected refusal. If the port is reused unexpectedly, the test fails rather than declaring the result equivalent.

<!-- lab:exercise-083-run -->
```bash
cat > tests/check-loopback.py <<'PY'
from pathlib import Path
import socket
import subprocess
import sys
import tempfile
import time
import urllib.request

root = Path(__file__).resolve().parents[1]
opener = urllib.request.build_opener(urllib.request.ProxyHandler({}))
with tempfile.TemporaryDirectory(prefix='loopback-', dir=root / 'evidence') as temp:
    for mode in ('good', 'wrong'):
        ready = Path(temp) / (mode + '.port')
        child = subprocess.Popen([sys.executable, str(root / 'scripts/loopback-health.py'),
                                  '--ready', str(ready), '--mode', mode, '--seconds', '10'],
                                 stdout=subprocess.DEVNULL, stderr=subprocess.PIPE, text=True)
        port = None
        try:
            deadline = time.monotonic() + 5
            while not ready.exists():
                if child.poll() is not None:
                    raise AssertionError('helper exited before readiness: ' + child.stderr.read())
                if time.monotonic() >= deadline:
                    raise AssertionError('readiness deadline exceeded')
                time.sleep(0.02)
            port = int(ready.read_text())
            if not 1 <= port <= 65535:
                raise AssertionError('invalid assigned port')
            with opener.open('http://127.0.0.1:%s/health' % port, timeout=2) as response:
                status = response.status
                body = response.read(100)
            if status != 200:
                raise AssertionError('expected HTTP 200')
            accepted = body == b'READY\n'
            if accepted != (mode == 'good'):
                raise AssertionError('wrong application acceptance result')
            print('PASS: HTTP 200 with content acceptance=' + str(accepted))
        finally:
            if child.poll() is None:
                child.terminate()
            try:
                child.wait(timeout=3)
            except subprocess.TimeoutExpired:
                child.kill()
                child.wait(timeout=3)
            child.stderr.close()
        if ready.exists():
            raise AssertionError('helper readiness file was not cleaned up')
        try:
            connection = socket.create_connection(('127.0.0.1', port), timeout=1)
        except ConnectionRefusedError:
            print('PASS: stopped local listener refused connection')
        else:
            connection.close()
            raise AssertionError('endpoint unexpectedly accepted a connection after shutdown')
print('PASS: local children exited and temporary loopback evidence removed')
PY
python3 tests/check-loopback.py
```

# Part 8 — Implement your tool

<!-- lab:implementation -->
```bash
cat > scripts/connectivity-report.py <<'PY'
#!/usr/bin/env python3
"""Troubleshooting Network Connectivity — bounded evidence analysis for this lab."""
import argparse
import datetime as dt
import json
import math
from pathlib import Path
import stat
import sys


def integer(value, name, low=0, high=10**18):
    if type(value) is not int or not low <= value <= high:
        raise ValueError(name + ': expected an integer in the documented range')
    return value


def number(value, name, low=0, high=10**12):
    if type(value) not in (int, float) or not math.isfinite(value) or not low <= value <= high:
        raise ValueError(name + ': expected a finite number in the documented range')
    return value


def text(value, name):
    if not isinstance(value, str) or not value.strip() or len(value) > 1000:
        raise ValueError(name + ': expected nonempty bounded text')
    if any(ord(c) < 32 or ord(c) == 127 for c in value):
        raise ValueError(name + ': control characters are not allowed')
    return value


def fields(obj, names):
    if not isinstance(obj, dict) or set(obj) != set(names.split()):
        raise ValueError('expected exactly these fields: ' + names)


def reject_duplicates(pairs):
    result = {}
    for key, value in pairs:
        if key in result:
            raise ValueError('duplicate JSON key')
        result[key] = value
    return result


def load(path):
    # A private, trusted lab workspace is a prerequisite, not a hostile-directory sandbox.
    if path.is_symlink() or not stat.S_ISREG(path.stat().st_mode):
        raise ValueError('input must be a regular non-symlink file')
    with path.open('rb') as stream:
        data = stream.read(1024 * 1024 + 1)
    if len(data) > 1024 * 1024:
        raise ValueError('input exceeds the 1 MiB lab limit')
    return json.loads(data.decode('utf-8'), object_pairs_hook=reject_duplicates,
                      parse_constant=lambda _: (_ for _ in ()).throw(ValueError('nonfinite JSON value')))


def analyze(doc):
    stages = ('resolution', 'route', 'tcp', 'http', 'content')
    fields(doc, ' '.join(stages))
    first = None
    for stage in stages:
        if doc[stage] not in ('pass', 'fail', 'unknown'):
            raise ValueError('layer requires pass, fail or unknown')
        if first is not None and doc[stage] == 'pass':
            raise ValueError('later pass contradicts single-attempt layer model')
        if first is None and doc[stage] != 'pass': first = stage
    return int(first is not None), {
        'boundary': first, 'state': doc[first] if first else 'accepted-operation',
        'scope': 'supplied attempt only', 'automatic_network_change': False}


def main():
    parser = argparse.ArgumentParser(description=__doc__)
    parser.add_argument('input', type=Path, help='private lab JSON evidence file; never executed as code')
    args = parser.parse_args()
    try:
        status, report = analyze(load(args.input))
        print(json.dumps(report, sort_keys=True, indent=2, allow_nan=False))
        return status
    except (OSError, ValueError, TypeError, KeyError, OverflowError, RecursionError) as error:
        print('ERROR: ' + str(error), file=sys.stderr)
        return 2


if __name__ == '__main__':
    sys.exit(main())
PY
```

## Explain the implementation

`fields` rejects missing and unexpected object fields so a misspelling cannot silently become an absent observation. `integer` rejects booleans as numeric counters. `number` rejects nonfinite values. Those checks are deliberate: Python otherwise treats `True` as an integer, and permissive JSON parsers may accept nonstandard numeric constants.

`load` bounds the input size before decoding it and rejects duplicate keys. The `analyze` function contains your subject-specific decisions; walk through it with the supplied numbers and predict the report before running it. `main` prints JSON rather than terminal control sequences and keeps errors on stderr. It does not open a second evidence file, invoke a repair command or change host policy.

Your program has no execute permission requirement because you invoke it explicitly with `python3`. That keeps the interpreter choice visible. Do not run it as root merely because an input is inaccessible.

# Part 10 — Create and run your regression suite

The tests launch the actual CLI in fresh subprocesses, compare selected report fields and check meaningful nonzero statuses. They also reject malformed, duplicate-key, nonfinite, missing, oversized, directory and symbolic-link inputs. Test fixtures are private and removed after the run.

<!-- lab:tests -->
```bash
cat > tests/run-tests.py <<'PY'
#!/usr/bin/env python3
"""Run the documented fixture checks without inspecting or changing a host."""
import json
from pathlib import Path
import subprocess
import sys
import tempfile

ROOT = Path(__file__).resolve().parents[1]
TOOL = ROOT / 'scripts' / 'connectivity-report.py'
CASES = [('all recorded layers accepted', {'resolution': 'pass', 'route': 'pass', 'tcp': 'pass', 'http': 'pass', 'content': 'pass'}, 0, {'boundary': None, 'state': 'accepted-operation'}), ('name unresolved', {'resolution': 'fail', 'route': 'unknown', 'tcp': 'unknown', 'http': 'unknown', 'content': 'unknown'}, 1, {'boundary': 'resolution'}), ('TCP refusal', {'resolution': 'pass', 'route': 'pass', 'tcp': 'fail', 'http': 'unknown', 'content': 'unknown'}, 1, {'boundary': 'tcp'}), ('HTTP error', {'resolution': 'pass', 'route': 'pass', 'tcp': 'pass', 'http': 'fail', 'content': 'unknown'}, 1, {'boundary': 'http'}), ('HTTP success wrong content', {'resolution': 'pass', 'route': 'pass', 'tcp': 'pass', 'http': 'pass', 'content': 'fail'}, 1, {'boundary': 'content'}), ('contradictory layer record', {'resolution': 'pass', 'route': 'pass', 'tcp': 'fail', 'http': 'pass', 'content': 'pass'}, 2, {})]


def run(path):
    return subprocess.run([sys.executable, str(TOOL), str(path)],
                          capture_output=True, text=True, timeout=10)


def check(condition, message):
    if not condition:
        raise AssertionError(message)


count = 0
with tempfile.TemporaryDirectory(prefix='regression-', dir=ROOT / 'fixtures') as temp:
    folder = Path(temp)
    for name, document, status, expected in CASES:
        path = folder / 'case.json'
        path.write_text(json.dumps(document), encoding='utf-8')
        result = run(path)
        check(result.returncode == status, name + ': status: ' + result.stderr + result.stdout)
        if status != 2:
            report = json.loads(result.stdout)
            for key, value in expected.items():
                check(report.get(key) == value, name + ': unexpected ' + key + ': ' + result.stdout)
        else:
            check(not result.stdout and result.stderr.startswith('ERROR:'), name + ': error contract')
        print('PASS ' + name)
        count += 1
    for name, payload in [('bad-json', '{'), ('duplicate-key', '{"x":1,"x":2}'),
                          ('nonfinite', '{"x":NaN}'), ('invalid-utf8', b'\xff')]:
        path = folder / 'invalid.json'
        path.write_bytes(payload if isinstance(payload, bytes) else payload.encode('utf-8'))
        result = run(path)
        check(result.returncode == 2 and not result.stdout, name)
        print('PASS ' + name)
        count += 1
    missing = folder / 'missing.json'
    check(run(missing).returncode == 2, 'missing input')
    count += 1
    target = folder / 'target.json'
    target.write_text('{}', encoding='utf-8')
    link = folder / 'link.json'
    link.symlink_to(target)
    check(run(link).returncode == 2, 'symlink input')
    count += 1
    large = folder / 'large.json'
    large.write_bytes(b' ' * (1024 * 1024 + 1))
    check(run(large).returncode == 2, 'oversized input')
    count += 1
    check(run(folder).returncode == 2, 'directory input')
    count += 1
print('PASS: %s assertions; temporary test fixtures removed' % count)
PY
```

# Part 15 — Knowledge assessment

Answer these before reading the explanation. Demonstrate the answers with your own evidence where appropriate.

## 1. Does ping prove HTTP readiness?

No. ICMP reachability and the required HTTP operation are different boundaries.

## 2. Why bind only loopback?

The exercise needs no public exposure or remote client, so the listener stays local.

## 3. Why request port zero?

The OS assigns an available port, avoiding a guessed fixed-port collision.

## 4. Why disable proxy use in the test?

The controlled acceptance request must reach the exact local endpoint rather than an environment-configured proxy.

## 5. What does wrong-content mode prove?

HTTP 200 alone does not establish the expected application result.

## 6. Why retain the Popen object?

It identifies your exact child for shutdown and waiting, avoiding process-name matches or stale PID assumptions.

## 7. Is timeout equivalent to refusal?

No. They are different connection outcomes with different possible explanations.

## 8. What does the loopback test exclude?

Remote DNS, gateways, remote firewalls, TLS and multi-host availability.

## 9. Why can getent differ from a DNS-only query?

It follows the configured name-service path, which can include sources other than DNS.

## 10. What establishes cleanup?

Your exact children exited, readiness files and test directories were removed, and the old listener no longer accepts a connection.
