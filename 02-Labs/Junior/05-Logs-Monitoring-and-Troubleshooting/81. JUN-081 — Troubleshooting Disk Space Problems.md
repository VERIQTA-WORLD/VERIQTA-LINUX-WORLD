# Part 1 — Preserve the exact error and path

Record the attempted operation, acting account, path, timestamp and exact error. “No space left on device,” “Disk quota exceeded,” “Read-only file system” and “Permission denied” are not interchangeable. A dashboard symptom can hide those differences.

# Part 4 — Optional Linux-only kernel ENOSPC experiment

Use this extension only in a disposable Linux VM with authorized sudo access and a working console. It mounts an 8 MiB memory-backed filesystem under your unique workspace and caps inode allocation. Never substitute a real device or host mountpoint. Skip it when mount authority or recovery is unavailable.

First create an empty lab mountpoint and confirm it is not already a mount:

```bash
mkdir evidence/bounded-mount
findmnt --mountpoint "$lab/evidence/bounded-mount"
sudo mount -t tmpfs   -o "size=8M,nr_inodes=128,mode=0700,uid=$(id -u),gid=$(id -g)"   tmpfs "$lab/evidence/bounded-mount"
findmnt --mountpoint "$lab/evidence/bounded-mount"
```

The first findmnt should show no exact mount; confirm that before mounting. The second must show your exact tmpfs target and bounded options. If the target differs or mounting fails, stop. Do not run the writer unless the next script's mount/size preflight passes.

The writer checks the exact mount through findmnt JSON and bounds its attempts. It refuses to run against an ordinary directory or a larger filesystem:

```bash
python3 - <<'PY'
import errno
import json
import os
from pathlib import Path
import subprocess
p = Path('evidence/bounded-mount').resolve()
r = subprocess.run(['findmnt', '--json', '--mountpoint', str(p),
                    '--output', 'TARGET,FSTYPE'], check=True, capture_output=True, text=True)
entries = json.loads(r.stdout)['filesystems']
assert len(entries) == 1 and entries[0]['target'] == str(p) and entries[0]['fstype'] == 'tmpfs'
s = os.statvfs(p)
assert 0 < s.f_blocks * s.f_frsize <= 8 * 1024 * 1024
assert 0 < s.f_files <= 128
out = p / 'bounded-fill.bin'
try:
    with out.open('xb') as stream:
        for _ in range(40):
            stream.write(b'x' * (256 * 1024))
        stream.flush()
except OSError as error:
    if error.errno != errno.ENOSPC:
        raise
    print('Expected kernel ENOSPC inside the confirmed bounded tmpfs')
else:
    raise AssertionError('expected bounded ENOSPC not observed')
PY
df -Pk -- evidence/bounded-mount
df -Pi -- evidence/bounded-mount
```

You have bounded data pressure, not a host-root incident. Preserve the actual error and capacity output. An unexpectedly smaller inode limit can affect which allocation fails; inspect both resources rather than assuming the block test behaved identically on every kernel.

# Part 8 — Implement your tool

<!-- lab:implementation -->
```bash
cat > scripts/space-investigation.py <<'PY'
#!/usr/bin/env python3
"""Troubleshooting Disk Space Problems — bounded evidence analysis for this lab."""
import argparse
import datetime as dt
import json
import math
from pathlib import Path
import stat
import sys


def integer(value, name, low=0, high=10**18):
    if type(value) is not int or not low <= value <= high:
        raise ValueError(name + ': expected an integer in the documented range')
    return value


def number(value, name, low=0, high=10**12):
    if type(value) not in (int, float) or not math.isfinite(value) or not low <= value <= high:
        raise ValueError(name + ': expected a finite number in the documented range')
    return value


def text(value, name):
    if not isinstance(value, str) or not value.strip() or len(value) > 1000:
        raise ValueError(name + ': expected nonempty bounded text')
    if any(ord(c) < 32 or ord(c) == 127 for c in value):
        raise ValueError(name + ': control characters are not allowed')
    return value


def fields(obj, names):
    if not isinstance(obj, dict) or set(obj) != set(names.split()):
        raise ValueError('expected exactly these fields: ' + names)


def reject_duplicates(pairs):
    result = {}
    for key, value in pairs:
        if key in result:
            raise ValueError('duplicate JSON key')
        result[key] = value
    return result


def load(path):
    # A private, trusted lab workspace is a prerequisite, not a hostile-directory sandbox.
    if path.is_symlink() or not stat.S_ISREG(path.stat().st_mode):
        raise ValueError('input must be a regular non-symlink file')
    with path.open('rb') as stream:
        data = stream.read(1024 * 1024 + 1)
    if len(data) > 1024 * 1024:
        raise ValueError('input exceeds the 1 MiB lab limit')
    return json.loads(data.decode('utf-8'), object_pairs_hook=reject_duplicates,
                      parse_constant=lambda _: (_ for _ in ()).throw(ValueError('nonfinite JSON value')))


def analyze(doc):
    fields(doc, 'available_blocks available_inodes quota_exceeded read_only write_checks')
    blocks = integer(doc['available_blocks'], 'available_blocks')
    inodes = doc['available_inodes']
    if inodes is not None: integer(inodes, 'available_inodes')
    quota = doc['quota_exceeded']
    if quota is not None and type(quota) is not bool:
        raise ValueError('quota_exceeded must be boolean or null')
    if type(doc['read_only']) is not bool:
        raise ValueError('read_only must be boolean')
    checks = doc['write_checks']
    if not isinstance(checks, list) or len(checks) > 20 or any(type(x) is not bool for x in checks):
        raise ValueError('write_checks must be bounded booleans')
    constraints, unknown = [], []
    if blocks == 0: constraints.append('no ordinary-user blocks available')
    if inodes == 0: constraints.append('no inodes available')
    if inodes is None: unknown.append('inode accounting')
    if quota is True: constraints.append('quota exceeded')
    if quota is None: unknown.append('quota state')
    if doc['read_only']: constraints.append('read-only mount')
    recovered = len(checks) >= 3 and all(checks)
    return int(bool(constraints or unknown or not recovered)), {
        'constraints': constraints, 'unknown': unknown, 'write_recovery_recorded': recovered,
        'cause': 'requires error, path and workload evidence'}


def main():
    parser = argparse.ArgumentParser(description=__doc__)
    parser.add_argument('input', type=Path, help='private lab JSON evidence file; never executed as code')
    args = parser.parse_args()
    try:
        status, report = analyze(load(args.input))
        print(json.dumps(report, sort_keys=True, indent=2, allow_nan=False))
        return status
    except (OSError, ValueError, TypeError, KeyError, OverflowError, RecursionError) as error:
        print('ERROR: ' + str(error), file=sys.stderr)
        return 2


if __name__ == '__main__':
    sys.exit(main())
PY
```

## Explain the implementation

`fields` rejects missing and unexpected object fields so a misspelling cannot silently become an absent observation. `integer` rejects booleans as numeric counters. `number` rejects nonfinite values. Those checks are deliberate: Python otherwise treats `True` as an integer, and permissive JSON parsers may accept nonstandard numeric constants.

`load` bounds the input size before decoding it and rejects duplicate keys. The `analyze` function contains your subject-specific decisions; walk through it with the supplied numbers and predict the report before running it. `main` prints JSON rather than terminal control sequences and keeps errors on stderr. It does not open a second evidence file, invoke a repair command or change host policy.

Your program has no execute permission requirement because you invoke it explicitly with `python3`. That keeps the interpreter choice visible. Do not run it as root merely because an input is inaccessible.

# Part 10 — Create and run your regression suite

The tests launch the actual CLI in fresh subprocesses, compare selected report fields and check meaningful nonzero statuses. They also reject malformed, duplicate-key, nonfinite, missing, oversized, directory and symbolic-link inputs. Test fixtures are private and removed after the run.

<!-- lab:tests -->
```bash
cat > tests/run-tests.py <<'PY'
#!/usr/bin/env python3
"""Run the documented fixture checks without inspecting or changing a host."""
import json
from pathlib import Path
import subprocess
import sys
import tempfile

ROOT = Path(__file__).resolve().parents[1]
TOOL = ROOT / 'scripts' / 'space-investigation.py'
CASES = [('write recovery with capacity', {'available_blocks': 100, 'available_inodes': 10, 'quota_exceeded': False, 'read_only': False, 'write_checks': [True, True, True]}, 0, {'constraints': [], 'unknown': [], 'write_recovery_recorded': True}), ('block exhaustion', {'available_blocks': 0, 'available_inodes': 10, 'quota_exceeded': False, 'read_only': False, 'write_checks': [False]}, 1, {'constraints': ['no ordinary-user blocks available']}), ('inode exhaustion', {'available_blocks': 100, 'available_inodes': 0, 'quota_exceeded': False, 'read_only': False, 'write_checks': [True, True, True]}, 1, {'constraints': ['no inodes available']}), ('quota unknown', {'available_blocks': 100, 'available_inodes': 10, 'quota_exceeded': None, 'read_only': False, 'write_checks': [True, True, True]}, 1, {'unknown': ['quota state']}), ('read-only boundary', {'available_blocks': 100, 'available_inodes': 10, 'quota_exceeded': False, 'read_only': True, 'write_checks': [True, True, True]}, 1, {'constraints': ['read-only mount']}), ('negative available blocks', {'available_blocks': -1, 'available_inodes': 10, 'quota_exceeded': False, 'read_only': False, 'write_checks': [True, True, True]}, 2, {})]


def run(path):
    return subprocess.run([sys.executable, str(TOOL), str(path)],
                          capture_output=True, text=True, timeout=10)


def check(condition, message):
    if not condition:
        raise AssertionError(message)


count = 0
with tempfile.TemporaryDirectory(prefix='regression-', dir=ROOT / 'fixtures') as temp:
    folder = Path(temp)
    for name, document, status, expected in CASES:
        path = folder / 'case.json'
        path.write_text(json.dumps(document), encoding='utf-8')
        result = run(path)
        check(result.returncode == status, name + ': status: ' + result.stderr + result.stdout)
        if status != 2:
            report = json.loads(result.stdout)
            for key, value in expected.items():
                check(report.get(key) == value, name + ': unexpected ' + key + ': ' + result.stdout)
        else:
            check(not result.stdout and result.stderr.startswith('ERROR:'), name + ': error contract')
        print('PASS ' + name)
        count += 1
    for name, payload in [('bad-json', '{'), ('duplicate-key', '{"x":1,"x":2}'),
                          ('nonfinite', '{"x":NaN}'), ('invalid-utf8', b'\xff')]:
        path = folder / 'invalid.json'
        path.write_bytes(payload if isinstance(payload, bytes) else payload.encode('utf-8'))
        result = run(path)
        check(result.returncode == 2 and not result.stdout, name)
        print('PASS ' + name)
        count += 1
    missing = folder / 'missing.json'
    check(run(missing).returncode == 2, 'missing input')
    count += 1
    target = folder / 'target.json'
    target.write_text('{}', encoding='utf-8')
    link = folder / 'link.json'
    link.symlink_to(target)
    check(run(link).returncode == 2, 'symlink input')
    count += 1
    large = folder / 'large.json'
    large.write_bytes(b' ' * (1024 * 1024 + 1))
    check(run(large).returncode == 2, 'oversized input')
    count += 1
    check(run(folder).returncode == 2, 'directory input')
    count += 1
print('PASS: %s assertions; temporary test fixtures removed' % count)
PY
```

# Part 15 — Knowledge assessment

Answer these before reading the explanation. Demonstrate the answers with your own evidence where appropriate.

## 1. Why preserve exact error text?

ENOSPC, quota, read-only and permission failures point to different boundaries and repairs.

## 2. Why check the exact path’s mount?

A nested or overlay mount can have a different capacity limit than the host root filesystem.

## 3. Why inspect inodes separately?

File creation can fail from metadata exhaustion while blocks remain available.

## 4. What does private cleanup prove?

Only that the known disposable data was removed, retained data survived and the tested write succeeded.

## 5. Why not delete all logs?

They are operational evidence and may belong to active services; broad deletion can cause loss and fail to reclaim open storage.

## 6. What bounds the optional kernel experiment?

An exact verified tmpfs mount, at most 8 MiB capacity, at most 128 inodes and at most forty 256-KiB write attempts.

## 7. What if mount verification fails?

Stop before writing; never fall back to filling the parent filesystem.

## 8. What if unmount fails?

Stop deletion and investigate mount users; do not remove the directory or backing resources.

## 9. Does quota null mean no quota?

No. It is unknown and remains an attention condition.

## 10. How do you verify durable recovery?

Repeat the original application operation and observe capacity growth/retention behavior over a justified interval.
