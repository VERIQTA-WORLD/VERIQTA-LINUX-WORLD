# Part 1 — Locate the failure boundary before restarting

A service can fail before executing its program, exit because configuration is invalid, run with wrong content, or become unavailable after startup. Those cases require different evidence.

Start with loaded state, active/substate, main-process result, recent logs and the intended user operation. Do not turn “active” into a readiness assertion. A successful Type=exec launch confirms execution began; it does not prove the application reached its own acceptance criterion.

Your fixture analyzer below checks recorded observations. The real extension uses a private configuration and transient user unit with a maximum lifetime. If you have no working user manager, stop that extension and retain the supplied-data exercise; do not replace `--user` with sudo.

# Part 2 — Build a bounded demonstration application

The application validates a small configuration, writes a readiness file and exits after 15 seconds. This file is a deliberately simple lab acceptance surface, not a production readiness protocol. The config checker can run without systemd.

<!-- lab:exercise-079 -->
```bash
cat > scripts/demo-service.py <<'PY'
import json
from pathlib import Path
import sys
import time

def main():
    try:
        if len(sys.argv) not in (3, 4):
            raise ValueError('usage: config output [--check]')
        config = Path(sys.argv[1])
        if config.stat().st_size > 4096:
            raise ValueError('config too large')
        doc = json.loads(config.read_text())
        if not isinstance(doc, dict) or set(doc) != {'message'} or not isinstance(doc['message'], str) or not 1 <= len(doc['message']) <= 80:
            raise ValueError('message must be 1..80 characters')
        if len(sys.argv) == 4:
            if sys.argv[3] != '--check':
                raise ValueError('unknown mode')
            print('configuration accepted')
            return 0
        output = Path(sys.argv[2])
        output.write_text(doc['message'] + '\n')
        try:
            print('readiness file written', flush=True)
            time.sleep(15)
        finally:
            if output.exists():
                output.unlink()
        return 0
    except (OSError, ValueError, TypeError) as error:
        print('configuration/application error: ' + str(error), file=sys.stderr)
        return 2

sys.exit(main())
```

# Part 7 — Design the final tool before typing it

Your tool accepts one JSON evidence file. It reads at most 1 MiB, rejects malformed JSON, duplicate keys, nonfinite numbers, directories and final-component symbolic links, and validates the domain fields before printing a report. It never evaluates the input as shell or Python code.

| Exit status | Meaning |
| --- | --- |
| 0 | The documented analysis completed and its success criterion is met |
| 1 | Valid evidence requires attention, or the available evidence cannot establish the required outcome |
| 2 | Input, schema, range, collection or usage error; no normal report is printed |

A zero result concerns this tool's stated contract, not whole-system health. An attention result is different from malformed input. Your shell's status must be captured immediately after the command, before another command replaces it.

The analyzer requires a valid config assertion, active state and three successful application samples. It preserves reasons for configuration rejection, inactive/failed state, nonzero exit and incomplete/unstable acceptance. It consumes recorded assertions; it does not query systemd or prove their truth.

The file checks assume your private workspace is trusted. They are not race-proof protection against a malicious writer changing parent directories or files during a read. Do not expose the tool as a privileged service or point it at hostile paths.

<!-- lab:implementation -->
```bash
cat > scripts/service-evidence.py <<'PY'
#!/usr/bin/env python3
"""Troubleshooting a Failed Service — bounded evidence analysis for this lab."""
import argparse
import datetime as dt
import json
import math
from pathlib import Path
import stat
import sys


def integer(value, name, low=0, high=10**18):
    if type(value) is not int or not low <= value <= high:
        raise ValueError(name + ': expected an integer in the documented range')
    return value


def number(value, name, low=0, high=10**12):
    if type(value) not in (int, float) or not math.isfinite(value) or not low <= value <= high:
        raise ValueError(name + ': expected a finite number in the documented range')
    return value


def text(value, name):
    if not isinstance(value, str) or not value.strip() or len(value) > 1000:
        raise ValueError(name + ': expected nonempty bounded text')
    if any(ord(c) < 32 or ord(c) == 127 for c in value):
        raise ValueError(name + ': control characters are not allowed')
    return value


def fields(obj, names):
    if not isinstance(obj, dict) or set(obj) != set(names.split()):
        raise ValueError('expected exactly these fields: ' + names)


def reject_duplicates(pairs):
    result = {}
    for key, value in pairs:
        if key in result:
            raise ValueError('duplicate JSON key')
        result[key] = value
    return result


def load(path):
    # A private, trusted lab workspace is a prerequisite, not a hostile-directory sandbox.
    if path.is_symlink() or not stat.S_ISREG(path.stat().st_mode):
        raise ValueError('input must be a regular non-symlink file')
    with path.open('rb') as stream:
        data = stream.read(1024 * 1024 + 1)
    if len(data) > 1024 * 1024:
        raise ValueError('input exceeds the 1 MiB lab limit')
    return json.loads(data.decode('utf-8'), object_pairs_hook=reject_duplicates,
                      parse_constant=lambda _: (_ for _ in ()).throw(ValueError('nonfinite JSON value')))


def analyze(doc):
    fields(doc, 'config active main_status samples')
    if doc['config'] not in ('valid', 'invalid', 'unknown'):
        raise ValueError('invalid config assertion')
    if doc['active'] not in ('active', 'failed', 'inactive', 'unknown'):
        raise ValueError('invalid active assertion')
    integer(doc['main_status'], 'main_status', 0, 255)
    samples = doc['samples']
    if not isinstance(samples, list) or len(samples) > 20 or any(type(x) is not bool for x in samples):
        raise ValueError('samples must be bounded booleans')
    reasons = []
    if doc['config'] != 'valid': reasons.append('configuration not validated')
    if doc['active'] != 'active': reasons.append('service not currently active')
    if doc['main_status'] != 0: reasons.append('nonzero main-process result')
    if len(samples) < 3 or not all(samples): reasons.append('application acceptance not demonstrated')
    return int(bool(reasons)), {'readiness': 'not-established' if reasons else 'demonstrated-in-supplied-window',
                               'reasons': reasons}


def main():
    parser = argparse.ArgumentParser(description=__doc__)
    parser.add_argument('input', type=Path, help='private lab JSON evidence file; never executed as code')
    args = parser.parse_args()
    try:
        status, report = analyze(load(args.input))
        print(json.dumps(report, sort_keys=True, indent=2, allow_nan=False))
        return status
    except (OSError, ValueError, TypeError, KeyError, OverflowError, RecursionError) as error:
        print('ERROR: ' + str(error), file=sys.stderr)
        return 2


if __name__ == '__main__':
    sys.exit(main())
PY
```

## Explain the implementation

`fields` rejects missing and unexpected object fields so a misspelling cannot silently become an absent observation. `integer` rejects booleans as numeric counters. `number` rejects nonfinite values. Those checks are deliberate: Python otherwise treats `True` as an integer, and permissive JSON parsers may accept nonstandard numeric constants.

`load` bounds the input size before decoding it and rejects duplicate keys. The `analyze` function contains your subject-specific decisions; walk through it with the supplied numbers and predict the report before running it. `main` prints JSON rather than terminal control sequences and keeps errors on stderr. It does not open a second evidence file, invoke a repair command or change host policy.

Your program has no execute permission requirement because you invoke it explicitly with `python3`. That keeps the interpreter choice visible. Do not run it as root merely because an input is inaccessible.

# Part 10 — Create and run your regression suite

The tests launch the actual CLI in fresh subprocesses, compare selected report fields and check meaningful nonzero statuses. They also reject malformed, duplicate-key, nonfinite, missing, oversized, directory and symbolic-link inputs. Test fixtures are private and removed after the run.

<!-- lab:tests -->
```bash
cat > tests/run-tests.py <<'PY'
#!/usr/bin/env python3
"""Run the documented fixture checks without inspecting or changing a host."""
import json
from pathlib import Path
import subprocess
import sys
import tempfile

ROOT = Path(__file__).resolve().parents[1]
TOOL = ROOT / 'scripts' / 'service-evidence.py'
CASES = [('valid active accepted service', {'config': 'valid', 'active': 'active', 'main_status': 0, 'samples': [True, True, True]}, 0, {'readiness': 'demonstrated-in-supplied-window', 'reasons': []}), ('config rejected', {'config': 'invalid', 'active': 'failed', 'main_status': 2, 'samples': []}, 1, {'readiness': 'not-established'}), ('active wrong response', {'config': 'valid', 'active': 'active', 'main_status': 0, 'samples': [False, False, False]}, 1, {'reasons': ['application acceptance not demonstrated']}), ('single successful response', {'config': 'valid', 'active': 'active', 'main_status': 0, 'samples': [True]}, 1, {'readiness': 'not-established'}), ('inactive previous success', {'config': 'valid', 'active': 'inactive', 'main_status': 0, 'samples': [True, True, True]}, 1, {'reasons': ['service not currently active']}), ('boolean exit status', {'config': 'valid', 'active': 'active', 'main_status': False, 'samples': [True, True, True]}, 2, {})]


def run(path):
    return subprocess.run([sys.executable, str(TOOL), str(path)],
                          capture_output=True, text=True, timeout=10)


def check(condition, message):
    if not condition:
        raise AssertionError(message)


count = 0
with tempfile.TemporaryDirectory(prefix='regression-', dir=ROOT / 'fixtures') as temp:
    folder = Path(temp)
    for name, document, status, expected in CASES:
        path = folder / 'case.json'
        path.write_text(json.dumps(document), encoding='utf-8')
        result = run(path)
        check(result.returncode == status, name + ': status: ' + result.stderr + result.stdout)
        if status != 2:
            report = json.loads(result.stdout)
            for key, value in expected.items():
                check(report.get(key) == value, name + ': unexpected ' + key + ': ' + result.stdout)
        else:
            check(not result.stdout and result.stderr.startswith('ERROR:'), name + ': error contract')
        print('PASS ' + name)
        count += 1
    for name, payload in [('bad-json', '{'), ('duplicate-key', '{"x":1,"x":2}'),
                          ('nonfinite', '{"x":NaN}'), ('invalid-utf8', b'\xff')]:
        path = folder / 'invalid.json'
        path.write_bytes(payload if isinstance(payload, bytes) else payload.encode('utf-8'))
        result = run(path)
        check(result.returncode == 2 and not result.stdout, name)
        print('PASS ' + name)
        count += 1
    missing = folder / 'missing.json'
    check(run(missing).returncode == 2, 'missing input')
    count += 1
    target = folder / 'target.json'
    target.write_text('{}', encoding='utf-8')
    link = folder / 'link.json'
    link.symlink_to(target)
    check(run(link).returncode == 2, 'symlink input')
    count += 1
    large = folder / 'large.json'
    large.write_bytes(b' ' * (1024 * 1024 + 1))
    check(run(large).returncode == 2, 'oversized input')
    count += 1
    check(run(folder).returncode == 2, 'directory input')
    count += 1
print('PASS: %s assertions; temporary test fixtures removed' % count)
PY
```

# Part 13 — Troubleshooting your lab

| Symptom | What you should check next |
| --- | --- |
| Command not found | Confirm the named tool and interpreter exist in the intended VM; follow its supported package workflow. |
| Permission denied | Verify the account, exact path and scope. Preserve the denial; do not apply broad permissions or run everything with sudo. |
| Status 2 from the analyzer | Read stderr, validate JSON syntax and compare the exact field names, units and ranges with the fixture. |

They scope this exercise to your account without persistent system-service changes or root authority.

It reduces collisions and lets you inspect and stop exactly the units created by this run.

The application exits after 15 seconds normally and the transient unit has a 20-second maximum runtime.

They are this bounded acceptance window, stronger than one response but still not a long-term availability guarantee.

Only the two transient units’ runtime/failed state and private marker; no system service is disabled.
