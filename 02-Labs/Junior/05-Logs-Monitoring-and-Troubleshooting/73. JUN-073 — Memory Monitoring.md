# Part 1 — Read available memory before proposing a change

Linux uses memory for application mappings, kernel allocations and caches. Low free memory alone does not establish a shortage: some cached memory can be reclaimed. `MemAvailable` estimates memory available for new work without swapping, while `MemFree` is a narrower count.

Do not add overlapping categories such as cached memory and reclaimable subdivisions blindly. Explain the fields you use and their units. Your final tool uses MemAvailable/Total as a deliberately small headroom measure; it does not reconstruct a full memory accounting identity.

A counter-based headroom check can be useful without proving pressure. Pressure describes time tasks are stalled; swap activity describes movement, whereas swap occupancy describes stored pages. Keep all three concepts separate.

# Part 2 — Collect a read-only baseline on Linux

On your VM, run:

```bash

sed -n '1,18p' /proc/meminfo

```

Record memory values in KiB when reading the proc fields labeled `kB`; in this interface that label represents 1024-byte units. `free -k` makes the comparison easier. Record the actual version of `free` if its columns differ.

Use subsequent vmstat interval rows when reasoning about current swap activity. A nonzero swap-used value can persist after earlier pressure; it is not proof that the current sample is thrashing. PSI may be unavailable or denied in your environment; record that rather than creating a substitute zero.

Do not disable swap, drop caches or allocate large byte arrays for this lab. Your controlled failures are supplied records. They teach the interpretation without risking the host.

# Part 3 — Define a measurement boundary

A container can have a memory limit much smaller than the host capacity. Host `/proc/meminfo` and cgroup memory accounting answer different questions. Record whether the process you are investigating is constrained by a cgroup, a VM allocation or the host.

The tool in this lab accepts a host-level meminfo excerpt encoded as JSON. It does not inspect cgroup limits. Before applying its percentage to a container, you would need a different collection contract and denominator. Do not infer unlimited capacity from the host's available memory.

For a real incident, correlate headroom with pressure, application latency, workload growth and kernel OOM evidence. A recent OOM record can explain a past process death; its absence in your accessible journal does not prove no OOM occurred.

# Part 8 — Implement your tool

Create the complete implementation. Read each function as you type it; do not skip straight to execution:

<!-- lab:implementation -->
```bash
cat > scripts/memory-headroom.py <<'PY'
#!/usr/bin/env python3
"""Memory Monitoring — bounded evidence analysis for this lab."""
import argparse
import datetime as dt
import json
import math
from pathlib import Path
import stat
import sys


def integer(value, name, low=0, high=10**18):
    if type(value) is not int or not low <= value <= high:
        raise ValueError(name + ': expected an integer in the documented range')
    return value


def number(value, name, low=0, high=10**12):
    if type(value) not in (int, float) or not math.isfinite(value) or not low <= value <= high:
        raise ValueError(name + ': expected a finite number in the documented range')
    return value


def text(value, name):
    if not isinstance(value, str) or not value.strip() or len(value) > 1000:
        raise ValueError(name + ': expected nonempty bounded text')
    if any(ord(c) < 32 or ord(c) == 127 for c in value):
        raise ValueError(name + ': control characters are not allowed')
    return value


def fields(obj, names):
    if not isinstance(obj, dict) or set(obj) != set(names.split()):
        raise ValueError('expected exactly these fields: ' + names)


def reject_duplicates(pairs):
    result = {}
    for key, value in pairs:
        if key in result:
            raise ValueError('duplicate JSON key')
        result[key] = value
    return result


def load(path):
    # A private, trusted lab workspace is a prerequisite, not a hostile-directory sandbox.
    if path.is_symlink() or not stat.S_ISREG(path.stat().st_mode):
        raise ValueError('input must be a regular non-symlink file')
    with path.open('rb') as stream:
        data = stream.read(1024 * 1024 + 1)
    if len(data) > 1024 * 1024:
        raise ValueError('input exceeds the 1 MiB lab limit')
    return json.loads(data.decode('utf-8'), object_pairs_hook=reject_duplicates,
                      parse_constant=lambda _: (_ for _ in ()).throw(ValueError('nonfinite JSON value')))


def analyze(doc):
    fields(doc, 'total_kib available_kib swap_total_kib swap_free_kib')
    total = integer(doc['total_kib'], 'total_kib', 1)
    swap_total = integer(doc['swap_total_kib'], 'swap_total_kib')
    swap_free = integer(doc['swap_free_kib'], 'swap_free_kib')
    if swap_free > swap_total:
        raise ValueError('swap free exceeds swap total')
    report = {'swap_used_kib': swap_total - swap_free,
              'scope': 'supplied host memory snapshot; pressure not measured'}
    if doc['available_kib'] is None:
        report.update({'state': 'unknown', 'available_percent': None})
        return 1, report
    available = integer(doc['available_kib'], 'available_kib')
    if available > total:
        raise ValueError('available memory exceeds total')
    attention = available * 10 <= total
    report.update({'state': 'attention' if attention else 'headroom-above-lab-threshold',
                   'available_percent': round(100 * available / total, 2)})
    return int(attention), report


def main():
    parser = argparse.ArgumentParser(description=__doc__)
    parser.add_argument('input', type=Path, help='private lab JSON evidence file; never executed as code')
    args = parser.parse_args()
    try:
        status, report = analyze(load(args.input))
        print(json.dumps(report, sort_keys=True, indent=2, allow_nan=False))
        return status
    except (OSError, ValueError, TypeError, KeyError, OverflowError, RecursionError) as error:
        print('ERROR: ' + str(error), file=sys.stderr)
        return 2


if __name__ == '__main__':
    sys.exit(main())
PY
```

## Explain the implementation

`fields` rejects missing and unexpected object fields so a misspelling cannot silently become an absent observation. `integer` rejects booleans as numeric counters. `number` rejects nonfinite values. Those checks are deliberate: Python otherwise treats `True` as an integer, and permissive JSON parsers may accept nonstandard numeric constants.

`load` bounds the input size before decoding it and rejects duplicate keys. The `analyze` function contains your subject-specific decisions; walk through it with the supplied numbers and predict the report before running it. `main` prints JSON rather than terminal control sequences and keeps errors on stderr. It does not open a second evidence file, invoke a repair command or change host policy.

Your program has no execute permission requirement because you invoke it explicitly with `python3`. That keeps the interpreter choice visible. Do not run it as root merely because an input is inaccessible.

# Part 10 — Create and run your regression suite

The tests launch the actual CLI in fresh subprocesses, compare selected report fields and check meaningful nonzero statuses. They also reject malformed, duplicate-key, nonfinite, missing, oversized, directory and symbolic-link inputs. Test fixtures are private and removed after the run.

<!-- lab:tests -->
```bash
cat > tests/run-tests.py <<'PY'
#!/usr/bin/env python3
"""Run the documented fixture checks without inspecting or changing a host."""
import json
from pathlib import Path
import subprocess
import sys
import tempfile

ROOT = Path(__file__).resolve().parents[1]
TOOL = ROOT / 'scripts' / 'memory-headroom.py'
CASES = [('normal headroom', {'total_kib': 1000000, 'available_kib': 400000, 'swap_total_kib': 500000, 'swap_free_kib': 450000}, 0, {'available_percent': 40.0, 'swap_used_kib': 50000}), ('exact ten-percent boundary', {'total_kib': 1000000, 'available_kib': 100000, 'swap_total_kib': 500000, 'swap_free_kib': 450000}, 1, {'state': 'attention', 'available_percent': 10.0}), ('unknown available', {'total_kib': 1000000, 'available_kib': None, 'swap_total_kib': 500000, 'swap_free_kib': 450000}, 1, {'state': 'unknown', 'available_percent': None}), ('available exceeds total', {'total_kib': 1000000, 'available_kib': 1000001, 'swap_total_kib': 500000, 'swap_free_kib': 450000}, 2, {}), ('swap free exceeds total', {'total_kib': 1000000, 'available_kib': 400000, 'swap_total_kib': 500000, 'swap_free_kib': 500001}, 2, {}), ('no swap configured', {'total_kib': 1000000, 'available_kib': 400000, 'swap_total_kib': 0, 'swap_free_kib': 0}, 0, {'swap_used_kib': 0})]


def run(path):
    return subprocess.run([sys.executable, str(TOOL), str(path)],
                          capture_output=True, text=True, timeout=10)


def check(condition, message):
    if not condition:
        raise AssertionError(message)


count = 0
with tempfile.TemporaryDirectory(prefix='regression-', dir=ROOT / 'fixtures') as temp:
    folder = Path(temp)
    for name, document, status, expected in CASES:
        path = folder / 'case.json'
        path.write_text(json.dumps(document), encoding='utf-8')
        result = run(path)
        check(result.returncode == status, name + ': status: ' + result.stderr + result.stdout)
        if status != 2:
            report = json.loads(result.stdout)
            for key, value in expected.items():
                check(report.get(key) == value, name + ': unexpected ' + key + ': ' + result.stdout)
        else:
            check(not result.stdout and result.stderr.startswith('ERROR:'), name + ': error contract')
        print('PASS ' + name)
        count += 1
    for name, payload in [('bad-json', '{'), ('duplicate-key', '{"x":1,"x":2}'),
                          ('nonfinite', '{"x":NaN}'), ('invalid-utf8', b'\xff')]:
        path = folder / 'invalid.json'
        path.write_bytes(payload if isinstance(payload, bytes) else payload.encode('utf-8'))
        result = run(path)
        check(result.returncode == 2 and not result.stdout, name)
        print('PASS ' + name)
        count += 1
    missing = folder / 'missing.json'
    check(run(missing).returncode == 2, 'missing input')
    count += 1
    target = folder / 'target.json'
    target.write_text('{}', encoding='utf-8')
    link = folder / 'link.json'
    link.symlink_to(target)
    check(run(link).returncode == 2, 'symlink input')
    count += 1
    large = folder / 'large.json'
    large.write_bytes(b' ' * (1024 * 1024 + 1))
    check(run(large).returncode == 2, 'oversized input')
    count += 1
    check(run(folder).returncode == 2, 'directory input')
    count += 1
print('PASS: %s assertions; temporary test fixtures removed' % count)
PY
```

# Part 15 — Knowledge assessment

Answer these before reading the explanation. Demonstrate the answers with your own evidence where appropriate.

## 1. Why is MemFree not your primary headroom measure?

It excludes memory that may be reclaimable; low free memory alone is not a complete shortage diagnosis.

## 2. Is MemAvailable an exact promise?

No. It is an estimate whose usefulness depends on workload and allocation behavior.

## 3. Can you add every meminfo field to reproduce total RAM?

No. Several fields overlap or describe subsets.

## 4. Does swap used prove current thrashing?

No. Occupancy can remain after activity has stopped; use interval activity and pressure evidence.

## 5. What does a missing available value produce?

An unknown state and attention status, never a fabricated zero or healthy result.

## 6. What does no configured swap mean for the report?

Zero swap total and free is valid and yields zero used; it does not establish memory pressure or a recommended policy.

## 7. Why record the cgroup boundary?

The constrained workload may have less usable memory than the host-level denominator.

## 8. What is special about exactly ten percent?

It meets this lab’s inclusive attention boundary; the threshold is explicitly a teaching choice.

## 9. Why reject available above total?

Those values cannot satisfy this snapshot’s declared contract and would produce misleading headroom.

## 10. Which next observations support a memory-pressure hypothesis?
