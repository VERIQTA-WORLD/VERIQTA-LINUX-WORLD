# Part 1 — Ask which operation fails as which account

“Permission denied” describes an operation under an identity and policy boundary. Reading a file, listing its directory and creating a new entry need different permissions. Start with the exact path, operation and effective account, not a broad recursive change.

On your Linux VM, inspect your identity and the private path:

```bash
id
ls -ld -- "$lab" "$lab/evidence"
namei -l -- "$lab/evidence"
```

`namei` helps you inspect each path component. Search/execute permission on every ancestor directory matters when resolving a known filename. Directory read permission controls listing names; it does not replace traversal permission.

For a service, inspect its configured identity and effective runtime context before testing as your interactive account. A root test can hide the very denial an ordinary service user experiences.

# Part 3 — Select the applicable mode class correctly

For ordinary mode-bit selection, owner bits apply when the effective UID matches the owner; otherwise matching group membership selects group bits; otherwise other bits apply. Do not fall through to other bits merely because the owner class denies access.

For your final tool, modes are strings such as `0640`. The four-character string prevents decimal/octal ambiguity in JSON. Only the basic permission bits are modeled. Root/capability exceptions, ACLs, mandatory access policy, mount restrictions and application checks are outside this model.

The supplied subject must have positive effective UID and a list of primary/supplementary GIDs. Each ancestor must allow search, then the target must allow read. The model does not check directory listing, file creation, rename or deletion.

# Part 5 — Predict the path result before using the tool

In the normal fixture, UID 1001 belongs to GID 2001. The directory is owned by another UID but has group mode 5, so it permits search. The target's group mode 4 permits reading. Your tool should report `mode-permits`.

If the directory's group bits lose search while the file stays readable, path resolution fails earlier. If the subject becomes the owner of a `0004` file, the owner class denies read even though other-read is set. These cases test the access model rather than merely parsing an octal string.

<!-- lab:implementation -->
```bash
cat > scripts/permission-path.py <<'PY'
#!/usr/bin/env python3
"""Troubleshooting Permission Problems — bounded evidence analysis for this lab."""
import argparse
import datetime as dt
import json
import math
from pathlib import Path
import stat
import sys


def integer(value, name, low=0, high=10**18):
    if type(value) is not int or not low <= value <= high:
        raise ValueError(name + ': expected an integer in the documented range')
    return value


def number(value, name, low=0, high=10**12):
    if type(value) not in (int, float) or not math.isfinite(value) or not low <= value <= high:
        raise ValueError(name + ': expected a finite number in the documented range')
    return value


def text(value, name):
    if not isinstance(value, str) or not value.strip() or len(value) > 1000:
        raise ValueError(name + ': expected nonempty bounded text')
    if any(ord(c) < 32 or ord(c) == 127 for c in value):
        raise ValueError(name + ': control characters are not allowed')
    return value


def fields(obj, names):
    if not isinstance(obj, dict) or set(obj) != set(names.split()):
        raise ValueError('expected exactly these fields: ' + names)


def reject_duplicates(pairs):
    result = {}
    for key, value in pairs:
        if key in result:
            raise ValueError('duplicate JSON key')
        result[key] = value
    return result


def load(path):
    # A private, trusted lab workspace is a prerequisite, not a hostile-directory sandbox.
    if path.is_symlink() or not stat.S_ISREG(path.stat().st_mode):
        raise ValueError('input must be a regular non-symlink file')
    with path.open('rb') as stream:
        data = stream.read(1024 * 1024 + 1)
    if len(data) > 1024 * 1024:
        raise ValueError('input exceeds the 1 MiB lab limit')
    return json.loads(data.decode('utf-8'), object_pairs_hook=reject_duplicates,
                      parse_constant=lambda _: (_ for _ in ()).throw(ValueError('nonfinite JSON value')))


def analyze(doc):
    import re
    fields(doc, 'subject_uid subject_gids ancestors target')
    uid = integer(doc['subject_uid'], 'subject_uid', 1)
    gids = doc['subject_gids']
    if not isinstance(gids, list) or not 1 <= len(gids) <= 100:
        raise ValueError('subject_gids: expected 1..100 group IDs')
    for gid in gids: integer(gid, 'gid')
    if not isinstance(doc['ancestors'], list) or not 1 <= len(doc['ancestors']) <= 20:
        raise ValueError('ancestors: expected 1..20 path components')
    def selected_bits(item):
        fields(item, 'owner_uid group_gid mode')
        owner = integer(item['owner_uid'], 'owner_uid')
        group = integer(item['group_gid'], 'group_gid')
        if not isinstance(item['mode'], str) or not re.fullmatch(r'0[0-7]{3}', item['mode']):
            raise ValueError('mode requires a four-character basic octal string')
        mode = int(item['mode'], 8)
        return (mode >> 6) & 7 if uid == owner else ((mode >> 3) & 7 if group in gids else mode & 7)
    denied = []
    for index, item in enumerate(doc['ancestors']):
        if not selected_bits(item) & 1:
            denied.append('ancestor-' + str(index) + '-search')
    if not selected_bits(doc['target']) & 4:
        denied.append('target-read')
    return int(bool(denied)), {'mode_result': 'mode-denies' if denied else 'mode-permits',
                              'denied': denied, 'full_policy': 'not evaluated'}


def main():
    parser = argparse.ArgumentParser(description=__doc__)
    parser.add_argument('input', type=Path, help='private lab JSON evidence file; never executed as code')
    args = parser.parse_args()
    try:
        status, report = analyze(load(args.input))
        print(json.dumps(report, sort_keys=True, indent=2, allow_nan=False))
        return status
    except (OSError, ValueError, TypeError, KeyError, OverflowError, RecursionError) as error:
        print('ERROR: ' + str(error), file=sys.stderr)
        return 2


if __name__ == '__main__':
    sys.exit(main())
PY
```

## Explain the implementation

`fields` rejects missing and unexpected object fields so a misspelling cannot silently become an absent observation. `integer` rejects booleans as numeric counters. `number` rejects nonfinite values. Those checks are deliberate: Python otherwise treats `True` as an integer, and permissive JSON parsers may accept nonstandard numeric constants.

`load` bounds the input size before decoding it and rejects duplicate keys. The `analyze` function contains your subject-specific decisions; walk through it with the supplied numbers and predict the report before running it. `main` prints JSON rather than terminal control sequences and keeps errors on stderr. It does not open a second evidence file, invoke a repair command or change host policy.

Your program has no execute permission requirement because you invoke it explicitly with `python3`. That keeps the interpreter choice visible. Do not run it as root merely because an input is inaccessible.

```bash
#!/usr/bin/env python3
"""Run the documented fixture checks without inspecting or changing a host."""
import json
from pathlib import Path
import subprocess
import sys
import tempfile

ROOT = Path(__file__).resolve().parents[1]
TOOL = ROOT / 'scripts' / 'permission-path.py'
CASES = [('group traversal and read', {'subject_uid': 1001, 'subject_gids': [2001], 'ancestors': [{'owner_uid': 1000, 'group_gid': 2001, 'mode': '0750'}], 'target': {'owner_uid': 1000, 'group_gid': 2001, 'mode': '0640'}}, 0, {'mode_result': 'mode-permits', 'denied': [], 'full_policy': 'not evaluated'}), ('parent lacks search', {'subject_uid': 1001, 'subject_gids': [2001], 'ancestors': [{'owner_uid': 1000, 'group_gid': 2001, 'mode': '0740'}], 'target': {'owner_uid': 1000, 'group_gid': 2001, 'mode': '0640'}}, 1, {'denied': ['ancestor-0-search']}), ('file lacks group read', {'subject_uid': 1001, 'subject_gids': [2001], 'ancestors': [{'owner_uid': 1000, 'group_gid': 2001, 'mode': '0750'}], 'target': {'owner_uid': 1000, 'group_gid': 2001, 'mode': '0600'}}, 1, {'denied': ['target-read']}), ('owner does not fall through', {'subject_uid': 1000, 'subject_gids': [2001], 'ancestors': [{'owner_uid': 1000, 'group_gid': 2001, 'mode': '0750'}], 'target': {'owner_uid': 1000, 'group_gid': 2001, 'mode': '0004'}}, 1, {'denied': ['target-read']}), ('root outside model', {'subject_uid': 0, 'subject_gids': [2001], 'ancestors': [{'owner_uid': 1000, 'group_gid': 2001, 'mode': '0750'}], 'target': {'owner_uid': 1000, 'group_gid': 2001, 'mode': '0640'}}, 2, {}), ('decimal-looking mode rejected', {'subject_uid': 1001, 'subject_gids': [2001], 'ancestors': [{'owner_uid': 1000, 'group_gid': 2001, 'mode': '0750'}], 'target': {'owner_uid': 1000, 'group_gid': 2001, 'mode': '640'}}, 2, {})]


def run(path):
    return subprocess.run([sys.executable, str(TOOL), str(path)],
                          capture_output=True, text=True, timeout=10)


def check(condition, message):
    if not condition:
        raise AssertionError(message)


count = 0
with tempfile.TemporaryDirectory(prefix='regression-', dir=ROOT / 'fixtures') as temp:
    folder = Path(temp)
    for name, document, status, expected in CASES:
        path = folder / 'case.json'
        path.write_text(json.dumps(document), encoding='utf-8')
        result = run(path)
        check(result.returncode == status, name + ': status: ' + result.stderr + result.stdout)
        if status != 2:
            report = json.loads(result.stdout)
            for key, value in expected.items():
                check(report.get(key) == value, name + ': unexpected ' + key + ': ' + result.stdout)
        else:
            check(not result.stdout and result.stderr.startswith('ERROR:'), name + ': error contract')
        print('PASS ' + name)
        count += 1
    for name, payload in [('bad-json', '{'), ('duplicate-key', '{"x":1,"x":2}'),
                          ('nonfinite', '{"x":NaN}'), ('invalid-utf8', b'\xff')]:
        path = folder / 'invalid.json'
        path.write_bytes(payload if isinstance(payload, bytes) else payload.encode('utf-8'))
        result = run(path)
        check(result.returncode == 2 and not result.stdout, name)
        print('PASS ' + name)
        count += 1
    missing = folder / 'missing.json'
    check(run(missing).returncode == 2, 'missing input')
    count += 1
    target = folder / 'target.json'
    target.write_text('{}', encoding='utf-8')
    link = folder / 'link.json'
    link.symlink_to(target)
    check(run(link).returncode == 2, 'symlink input')
    count += 1
    large = folder / 'large.json'
    large.write_bytes(b' ' * (1024 * 1024 + 1))
    check(run(large).returncode == 2, 'oversized input')
    count += 1
    check(run(folder).returncode == 2, 'directory input')
    count += 1
print('PASS: %s assertions; temporary test fixtures removed' % count)
PY
```

# Part 15 — Knowledge assessment

Answer these before reading the explanation. Demonstrate the answers with your own evidence where appropriate.

## 1. Why inspect the acting account first?

Access is evaluated under its effective identity and groups, which may differ from your interactive shell.

## 2. Does a directory need read permission to resolve a known child name?

Search/execute is the key traversal permission; listing names is a separate operation.

## 3. Can owner denial fall through to other-read?

No. The applicable class is selected by identity before its permission bits are evaluated.

## 4. Why use octal strings in JSON?

JSON numbers are decimal; an explicit four-character octal string avoids ambiguous interpretation.

## 5. Does mode-permits prove access succeeds?

No. ACLs, capabilities, mandatory policy, mounts and application checks are outside this model.

## 6. Why reject UID zero?

Root/capability behavior needs a different model and would invalidate the ordinary-user denial exercise.

## 7. Why restore modes in finally?

An assertion failure should not strand your private path in an inaccessible state.

## 8. Can chmod 777 identify the cause?

No. It broadens access and can hide the defect without establishing the required permission.

## 9. What does an ACL mask affect?

It constrains effective permissions for relevant ACL entries; inspect actual ACL semantics before changing it.

## 10. What verifies a repair?

The intended operation succeeds as the affected identity and required unauthorized operations remain denied.
