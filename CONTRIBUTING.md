# Feedback and contributions

Report incorrect explanations, broken links and differences you observe on Linux. Include the page, distribution/version, command and a redacted description of expected versus actual behavior. Never post credentials, private incident evidence or unauthorized material.

Read the [content standard](CONTENT-STANDARD.md) and [custom license](LICENSE.md). The personal-study license does not grant general permission to modify or redistribute repository content. Request written permission from the repository owner before preparing or publishing adaptations or patches that require such permission. Ordinary factual feedback and links to original documentation are welcome.

For an authorized contribution, agree in writing on the rights needed to include it under this repository’s custom license before submission. Do not submit material whose terms you cannot grant. Include isolated setup, commands, expected observations, actual verification, distribution differences and cleanup; follow the [folder 4 validation checklist](04-command-reference/VALIDATION.md) when relevant.
